# 03 · Platform Availability & Downloads

## Where you can get Stillora

| Platform | Status | How it's delivered |
|---|---|---|
| **Web App** | Live | Runs in any browser, no install |
| **iOS** | Live | Apple App Store — "Stillora - MP4 Video Maker" (universal iPhone/iPad) |
| **macOS** | Live | Same App Store universal listing (Apple Silicon Macs) |
| **Android** | Live | Google Play — `app.loopara.stillora`; a signed APK is also served from Stillora's domain for sideloading |
| **Windows** | Live | Zipped desktop build from Stillora's domain |
| **Linux** | Marketed as available | Desktop build |

Download links are **admin-managed per platform** — each can point to an uploaded binary served from Stillora's own domain or to an external store link, each with its own version label.

## Platform selling points (from the site)

- **Web App:** No install · full-resolution export · drag-and-drop uploads · works on any device.
- **Mobile App:** Full editor on the go · native camera upload · direct share to apps · offline export.
- **Desktop App:** Batch processing · local file access · faster FFmpeg encoding · pro-grade controls.
